# Body Ops v2.0.0 App Store 申請資料

作成日: 2026-07-12 / 対象ビルド: MARKETING_VERSION 2.0.0 (CURRENT_PROJECT_VERSION 2)

---

## 1. このバージョンの新機能（What's New — App Store Connectにそのまま貼り付け）

```
大型アップデート！記録のしやすさとAI機能を全面的に改良しました。

■ 記録がもっとカンタンに
・筋トレ記録にカレンダー付きの開始画面を新設。前回のメニューをワンタップで読み込めるほか、過去の日を選んでコピーもできます
・種目を選ぶと前回の重量・回数が自動入力されます
・食事記録は「写真からAI推定」「テキストからAI推定」「手動で入力」の3方式から選べるように。過去の食事のコピーにも対応しました

■ グラフが専用タブに
・いつでもすぐグラフを確認できます。記録のある全種目の重量推移を表示
・「今週のトレーニング」サマリー(先週比・今月の回数・連続週数)を追加
・期間指定を拡張(1週間〜全期間、開始日・終了日の指定も可能)

■ AIコーチを強化
・回答がリアルタイムに表示されるようになりました(考え中の状態表示・途中停止も可能)
・会話履歴を保存。アプリを再起動しても続きから相談できます
・新プロバイダー「Apple Intelligence(オンデバイス・無料)」を追加。APIキー不要で、データが端末の外に送信されません(iOS 26以降の対応端末)

■ その他の改善
・「今日」と「履歴」を「記録」タブに統合し、タブ構成を整理
・栄養素の数値入力を改善(キーボードに「完了」ボタンを追加)
・キーボード表示中にチャット入力欄が隠れる問題を修正
・安定性・保守性の向上
```

※ 詳細な変更一覧はリポジトリの `CHANGELOG.md` [2.0.0] セクションを参照。

## 3. アップロード手順

事前条件（確認済み）:
- Xcode 26.6 / iOS 26.5 SDK でビルド・全テスト成功
- 署名: DEVELOPMENT_TEAM `9472GD6P88` を project.yml に設定済み（xcodegen再生成でも消えない）
- バージョン: 2.0.0 / ビルド番号: 2

### 手順

1. **最新状態の確認**
   ```
   git checkout main && git pull   # ローカルのみ運用ならpull不要
   xcodegen generate
   ```
2. **配布用証明書**: Archive には「Apple Distribution」証明書が必要。
   Xcode → Settings → Accounts → 自分のApple ID → Team選択 → Manage Certificates → 「+」→ Apple Distribution（未作成の場合のみ）
3. **アーカイブ**: Xcodeで `BodyOps` スキーム選択 → ビルド先を **Any iOS Device (arm64)** に → メニュー **Product → Archive**
4. **アップロード**: Organizer が開いたら該当アーカイブを選択 → **Distribute App** → **App Store Connect** → **Upload**（署名は Automatically manage signing でOK）
5. **App Store Connect** (https://appstoreconnect.apple.com):
   - マイApp → Body Ops → 「+」で **新しいバージョン 2.0.0** を作成
   - 「このバージョンの新機能」に上記①のテキストを貼り付け
   - （任意）プロモーションテキストに②を貼り付け
   - ビルド欄で処理完了後のビルド 2.0.0 (2) を選択（アップロード後、処理に10〜30分かかることあり）
   - **スクリーンショット更新を推奨**: タブ構成・記録画面・食事入力・グラフのUIが大きく変わったため、旧スクショのままだと審査で指摘される可能性あり（必須ではないが強く推奨）
6. **App privacy / 輸出コンプライアンス**: 変更なし（HTTPS標準暗号のみ→輸出コンプライアンスは従来どおり「いいえ」でOK。データ収集も従来どおり変更なし）
7. **審査メモ（Notes欄）に記載推奨**:
   ```
   AI機能はユーザー自身のAPIキー（Claude/OpenAI/Gemini）または
   Apple Intelligence（オンデバイス）で動作します。
   審査時はAPIキーなしでも記録機能はすべて動作します。
   AIチャットを確認する場合はApple Intelligence対応端末で
   設定→AIプロバイダー→Apple Intelligenceを選択してください。
   ```
8. **審査に提出** → 承認後リリース
